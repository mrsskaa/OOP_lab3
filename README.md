# OOP_lab3

Лабораторная работа 3, вариант 10: `Interval` и `IntervalSet`. C++20, CMake, Google Test, AddressSanitizer.

Множество хранит динамический массив непересекающихся интервалов, отсортированных по левой границе. При добавлении пересекающиеся и касающиеся отрезки объединяются: `[1, 3]` и `[3, 5]` превращаются в `[1, 5]`.

## Файлы

- `include/lab03/interval.hpp`, `src/interval.cpp` — элемент множества.
- `include/lab03/interval_set.hpp`, `src/interval_set.cpp` — множество и операции над ним.
- `src/main.cpp` — интерактивное меню для двух множеств A и B.
- `test/` — тесты Google Test.
- `EXPLANATION.md` — объяснение алгоритмов и короткий текст для защиты.

## Контракт

`Interval(left, right)` создаёт замкнутый отрезок. Границы должны быть конечными числами и `left <= right`. Неверные границы нарушают предусловие конструктора; в Debug это проверяется `assert`. Меню проверяет ввод до вызова конструктора.

Для точной разности предусмотрены признаки включения границ:

```cpp
Interval(1, 2, true, false)  // [1, 2)
```

Это нужно потому, что `[1, 5] - [2, 3] = [1, 2) ∪ (3, 5]`. Только замкнутыми отрезками такой результат представить нельзя. При совпадающих границах разрешён только замкнутый одноточечный отрезок. `(1, 2)` и `(2, 3)` не объединяются: точка 2 отсутствует. Если хотя бы один интервал включает точку касания, объединение возможно.

`size()` — количество канонических интервалов, а не точек. `add()` возвращает `false` для дубликата и для интервала, полностью покрытого существующим. `contains()`, `operator()` и `remove()` работают с точным элементом канонического массива: для `{ [1, 5] }` запрос `[2, 3]` не является отдельным элементом. Для геометрического вычитания используется `operator-`.

`|`, `&`, `-` возвращают геометрическое объединение, пересечение и разность без изменения операндов. `==` сравнивает канонические массивы, поэтому порядок добавления не влияет на равенство. Сравнение границ точное, без epsilon, чтобы порядок и равенство были согласованы.

Контейнеров STL, умных указателей и собственных шаблонов в реализации нет. Память: `new[]` / `delete[]`, правило пяти, copy-and-swap. Ёмкость растёт удвоением, удаление сдвигает элементы.

## Проверка

36 тестов Google Test прошли с ASan. Проверены слияние, касание, одноточечные интервалы, открытые границы, все операции множеств, правило пяти, независимость копии, повторное использование перемещённого объекта и 1000 добавлений.

Дополнительно выполнена проверка операций на 2025 парах интервалов со всеми допустимыми сочетаниями открытых и закрытых границ: 26325 проверок принадлежности точек. Утилита macOS `leaks` не смогла получить доступ к процессу в текущей среде (`Couldn't get task port`), поэтому результат проверки утечек ею не подтверждён. Дополнительно выполнен диагностический подсчёт `new[]` / `delete[]` при росте, копировании, перемещении, операциях множеств и уничтожении объектов: после 20 циклов работы с 1000 интервалами число неосвобождённых массивов равно 0. Это проверка баланса выделений в этих сценариях, а не полная замена анализатора утечек.
